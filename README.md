# Srinithi & Vishu Karthick – Wedding Invitation Website

A botanical garden-themed animated wedding invitation website celebrating the sacred union of **Srinithi K & Vishu Karthick P**.

Inspired by *The Sacred Garden* aesthetic, featuring:
- **Deckled Botanical Envelope Opening:** With glowing V&S royal wax seal and "TAP TO OPEN" interactive prompt.
- **Background Music:** Continuous repeating instrumental soundtrack with bottom-right floating play/pause controls.
- **Live Countdown Timer:** Counting down to Sunday, 13 December 2026, 7:00 AM IST with an interactive **Add to Calendar (.ics)** generator.
- **Event Schedule Timeline:** Complete chronological event timeline across both Saturday, 12 December and Sunday, 13 December 2026, animated with a scroll-driven pink watercolor rose blossom tracking the central timeline line.
- **Venue & Directions:** Poovayammal Thirumana Mandapam, Rasipuram with architectural rendering and one-click Google Maps directions.
- **Closing Blessings:** Dedicated couple photo and closing sign-off with royal V&S medallion.

---

## 🚀 Quick Start

### 1. Run Development Server
```bash
npm run dev
# or
node server.js
```
Open **`http://localhost:8080/`** in your browser.
